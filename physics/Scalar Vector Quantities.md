# Scalar and Vector Quantities

## Scalar Quantities

A **scalar quantity** is fully described by a single numerical value (magnitude) and a unit. It can be positive or negative.

Examples: mass, temperature, time, energy.

## Vector Quantities

A **vector quantity** requires three attributes:
- **Magnitude** (module) — the numerical value
- **Direction** — the line along which the vector acts
- **Sense** — the orientation along that direction (e.g., left/right, up/down)

Examples: displacement, force, velocity, electric field.

A vector $\vec{V}$ from origin $O$ to point $P$ is written as:

$$\vec{V} = \overrightarrow{OP} = P - O$$

## Decomposition into Rectangular Components

Given a vector $\vec{u}$ making an angle $\alpha$ with the $x$-axis:

$$u_x = |\vec{u}| \cos \alpha$$

$$u_y = |\vec{u}| \sin \alpha$$

where:
- $u_x$ — projection (component) of $\vec{u}$ onto the $x$-axis
- $u_y$ — projection (component) of $\vec{u}$ onto the $y$-axis
- $|\vec{u}|$ — magnitude (module) of the vector
- $\alpha$ — angle between the vector and the positive $x$-axis
