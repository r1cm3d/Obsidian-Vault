# Scientific Notation

A number is expressed in the form:

$$a \times 10^n$$

where:
- $a$ — coefficient, with $1 \leq a < 10$
- $n$ — integer exponent (positive or negative), indicating how many positions the decimal point must be shifted to recover the original number

## Rules

- **Large numbers** ($\gg 1$): the positive exponent $n$ indicates how many places the decimal moves to the **right**.

$$272\,000\,000 = 2.72 \times 10^{8}$$

- **Small numbers** ($\ll 1$): the negative exponent $n$ indicates how many places the decimal moves to the **left**.

$$0.000\,000\,56 = 5.6 \times 10^{-7}$$

## Common Physical Constants in Scientific Notation

| Quantity | Value |
|---|---|
| Speed of light in vacuum | $c = 3 \times 10^{8}\ \text{m/s}$ |
| Mass of the Sun | $M_\odot = 3.955 \times 10^{30}\ \text{kg}$ |
| Hydrogen atom radius | $r_H = 5 \times 10^{-9}\ \text{cm}$ |
| Proton charge | $e = 1.602\,176\,634 \times 10^{-19}\ \text{C}$ |
