## Project Overview

This is an Obsidian vault containing organized reference materials for mathematics and physics. The repository is structured as a knowledge base with markdown files covering various academic topics.

## Repository Structure

- `math/` - Mathematical reference materials including basic mathematics, algebra, functions, trigonometry, set theory, and number systems
- `physics/` - Physics reference materials covering SI units, vectors, thermodynamics, statics, and scientific notation
- `.obsidian/` - Obsidian configuration files for the vault workspace

## Content Organization

The vault follows a subject-based organization:

**Mathematics Topics:**
- Mathematics Index (entry point), Algebraic Properties, Exponentiation and Radicals
- Functions, Logarithms, Trigonometry
- Number Sets, Set Theory

**Physics Topics:**
- Physical Quantities and SI Units
- Vector Operations, Scalar/Vector Quantities
- Thermodynamics (Ideal Gas Laws, Phase Changes, Thermal Power)
- Statics, Scientific Notation

## File Conventions

- All content files are in Markdown format (`.md`)
- Files use descriptive names that clearly indicate the topic covered
- Content is structured for academic reference with clear headings and mathematical notation
- Files are organized by subject area in dedicated directories

## Working with Content

When editing or adding content:

- Use proper mathematical notation and formatting
- Keep content organized by subject matter
- Ensure consistency with existing file naming conventions

This vault is designed for use with Obsidian, so preserve:
