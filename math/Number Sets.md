# Number Sets

A classification of numbers based on their properties and definitions.

### 1. Hierarchy of Numbers
The relationship between the sets can be described as:
$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$$

---

### 2. Definitions

| Set | Symbol | Description | Examples |
| :--- | :---: | :--- | :--- |
| **Natural Numbers** | $\mathbb{N}$ | Counting numbers starting from 0 or 1. | $\{0, 1, 2, 3, ...\}$ |
| **Integers** | $\mathbb{Z}$ | Whole numbers including negative values. | $\{..., -2, -1, 0, 1, 2, ...\}$ |
| **Rational Numbers** | $\mathbb{Q}$ | Numbers that can be expressed as a fraction $p/q$. | $\{ \frac{p}{q} \mid p, q \in \mathbb{Z}, q \neq 0 \}$ |
| **Irrational Numbers** | $\mathbb{I}$ | Numbers that cannot be written as simple fractions. | $\{\pi, e, \sqrt{2}, \sqrt{3}\}$ |
| **Real Numbers** | $\mathbb{R}$ | The union of Rational and Irrational numbers. | $\mathbb{Q} \cup \mathbb{I}$ |
| **Complex Numbers** | $\mathbb{C}$ | Numbers with real and imaginary parts. | $\{a + bi \mid a, b \in \mathbb{R}, i^2 = -1\}$ |

---

### 3. Intervals on the Real Line
For $a, b \in \mathbb{R}$:

- **Closed Interval:** $[a, b] = \{x \in \mathbb{R} \mid a \leq x \leq b\}$
- **Open Interval:** $(a, b) = \{x \in \mathbb{R} \mid a < x < b\}$
- **Half-Open Interval:** $[a, b) = \{x \in \mathbb{R} \mid a \leq x < b\}$
- **Infinite Interval:** $(-\infty, a] = \{x \in \mathbb{R} \mid x \leq a\}$

---

### 4. Important Subsets (Special Notation)
- $\mathbb{R}^*$: Non-zero real numbers ($\mathbb{R} - \{0\}$).
- $\mathbb{R}_+$: Non-negative real numbers ($x \geq 0$).
- $\mathbb{R}_-$: Non-positive real numbers ($x \leq 0$).
- $\mathbb{Z}^+$: Positive integers $\{1, 2, 3, ...\}$.
