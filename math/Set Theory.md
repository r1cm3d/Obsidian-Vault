# Set Theory

### 1. Operations
| Operation | Symbol | Definition |
| :--- | :--- | :--- |
| **Union** | $A \cup B$ | $\{x \mid x \in A \lor x \in B\}$ |
| **Intersection** | $A \cap B$ | $\{x \mid x \in A \land x \in B\}$ |
| **Difference** | $A - B$ | $\{x \mid x \in A \land x \notin B\}$ |
| **Complement** | $A^c$ | $\{x \in U \mid x \notin A\}$ |

### 2. Algebraic Laws
- **Idempotent:** $A \cup A = A$ and $A \cap A = A$
- **Distributive:** $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$
- **De Morgan's Laws:** $(A \cup B)^c = A^c \cap B^c$ and $(A \cap B)^c = A^c \cup B^c$
- **Cardinality:** $n(A \cup B) = n(A) + n(B) - n(A \cap B)$
