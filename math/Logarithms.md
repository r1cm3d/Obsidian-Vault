# Logarithms
For $a, b, c > 0$ and $b, c \neq 1$:

| Name | Rule |
| :--- | :--- |
| **Product Rule** | $\log_b(ac) = \log_b a + \log_b c$ |
| **Quotient Rule** | $\log_b(\frac{a}{c}) = \log_b a - \log_b c$ |
| **Power Rule** | $\log_b(a^n) = n \log_b a$ |
| **Root Rule** | $\log_b(\sqrt[n]{a}) = \frac{1}{n} \log_b a$ |
| **Change of Base** | $\log_b a = \frac{\log_c a}{\log_c b}$ |
| **Base Identity** | $\log_b b = 1$ |
| **Zero Identity** | $\log_b 1 = 0$ |
| **Base Exponentiation** | $b^{\log_b a} = a$ |
| **Reciprocal Rule** | $\log_b a = \frac{1}{\log_a b}$ |
