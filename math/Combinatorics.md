# Combinatorics

### Permutations
Used when arranging **all** items of a set where the order matters.
$$P(n) = n!$$

### Partial Permutations (Arrangements)
Used when arranging a subset of $k$ items from a set of $n$ items where the order matters.
$$P(n, k) = A^n_k = \frac{n!}{(n - k)!}$$

### Combinations
Used when selecting a subset of $k$ items from a set of $n$ items where the order **does not** matter.
$$C(n, k) = \binom{n}{k} = \frac{n!}{k!(n - k)!}$$
