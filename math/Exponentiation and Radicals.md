# Exponentiation and Radicals

### 1. Laws of Exponents
| Name | Rule |
| :--- | :--- |
| **Product Rule** | $a^m \cdot a^n = a^{m+n}$ |
| **Quotient Rule** | $\frac{a^m}{a^n} = a^{m-n}$ |
| **Power of a Power** | $(a^m)^n = a^{m \cdot n}$ |
| **Power of a Product** | $(a \cdot b)^n = a^n \cdot b^n$ |
| **Power of a Quotient** | $(\frac{a}{b})^n = \frac{a^n}{b^n}$ |
| **Zero Exponent** | $a^0 = 1, a \neq 0$ |
| **Negative Exponent** | $a^{-n} = \frac{1}{a^n}$ |
| **Fractional Exponent** | $a^{\frac{m}{n}} = \sqrt[n]{a^m}$ |

### 2. Properties of Radicals
| Name | Rule |
| :--- | :--- |
| **Product Rule** | $\sqrt[n]{ab} = \sqrt[n]{a} \sqrt[n]{b}$ |
| **Quotient Rule** | $\sqrt[n]{\frac{a}{b}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}}$ |
| **Power of a Radical** | $(\sqrt[n]{a})^m = \sqrt[n]{a^m}$ |
| **Root of a Root** | $\sqrt[m]{\sqrt[n]{a}} = \sqrt[m \cdot n]{a}$ |
| **Simplification** | $\sqrt[n \cdot p]{a^{m \cdot p}} = \sqrt[n]{a^m}$ |
| **Factor Entry** | $a \sqrt[n]{b} = \sqrt[n]{a^n b}$ |
