# Common Algebraic Properties

| Property | Addition | Multiplication |
| :--- | :--- | :--- |
| **Commutative** | $a + b = b + a$ | $a \cdot b = b \cdot a$ |
| **Associative** | $(a + b) + c = a + (b + c)$ | $(a \cdot b) \cdot c = a \cdot (b \cdot c)$ |
| **Identity** | $a + 0 = a$ | $a \cdot 1 = a$ |
| **Inverse** | $a + (-a) = 0$ | $a \cdot a^{-1} = 1, a \neq 0$ |
| **Distributive** | $a(b + c) = ab + ac$ | $(a + b)c = ac + bc$ |
| **Zero Product** | $a \cdot 0 = 0$ | If $ab = 0 \implies a=0$ or $b=0$ |
| **Cancellation** | $a+c = b+c \implies a=b$ | $ac = bc \implies a=b, c \neq 0$ |
