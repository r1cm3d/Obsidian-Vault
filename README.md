## 🎯 Overview

This vault provides structured reference materials covering essential topics in mathematics and physics. Each topic is carefully organized with clear explanations, formulas, and cross-references to related concepts.

### Key Features

- **📖 Comprehensive Coverage**: 19+ reference topics across math and physics
- **🔗 Interconnected Navigation**: Consistent linking between related concepts
- **📐 Mathematical Notation**: Proper LaTeX formatting for formulas and equations
- **🧭 Easy Navigation**: Index-based organization with "Back to" navigation
- **🎓 Academic Focus**: Designed for educational and professional reference

## 🚀 Getting Started

### Prerequisites

- [Obsidian](https://obsidian.md/) (latest version recommended)
- Basic familiarity with mathematical notation

### Setup Instructions

1. **Download Obsidian**
   ```bash
   # Download from official website
   https://obsidian.md/download
   ```

2. **Clone this repository**
   ```bash
   git clone https://github.com/r1cm3d/Obsidian-Vault.git
   cd Obsidian-Vault
   ```

3. **Open in Obsidian**
   - Launch Obsidian
   - Click "Open folder as vault"
   - Select the cloned `Obsidian-Vault` directory
   - Click "Trust author and enable plugins" if prompted

4. **Start exploring**
   - Begin with `math/index.md` or `physics/index.md`
   - Use the graph view to visualize connections
   - Enable MathJax for proper equation rendering

## 📚 Content Overview

### Mathematics Topics

- **Core Algebra**: Properties, exponents, radicals, logarithms
- **Functions**: Mapping types, transformations, parity
- **Trigonometry**: Identities, formulas, special angles
- **Set Theory**: Operations, laws, cardinality
- **Number Systems**: Natural, rational, real, complex numbers

### Physics Topics

- **Fundamentals**: SI units, scalar/vector quantities, scientific notation
- **Mechanics**: Statics, vector operations, force analysis
- **Thermodynamics**: Gas laws, phase changes, thermal power, work, energy forms
- **Energy & Laws**: Kinetic/potential energy, thermodynamic laws, Carnot cycle

## 🎯 How to Use This Vault

### Navigation Patterns

1. **Index-First Approach**: Start at `math/index.md` or `physics/index.md`
2. **Topic Deep Dive**: Click any topic to explore detailed content
3. **Cross-References**: Follow `[[links]]` to related concepts
4. **Back Navigation**: Use "Back to: [[index]]" to return to topic lists

### Best Practices

- Use the search function (`Ctrl/Cmd + O`) to quickly find topics
- Enable the graph view to visualize concept relationships
- Bookmark frequently used reference materials
- Use tags `#study`, `#math`, `#physics` for organization

## 🔧 Configuration

### Recommended Obsidian Settings

```json
{
  "showFrontmatter": false,
  "showInlineTitle": true,
  "readableLineLength": false,
  "strictLineBreaks": false,
  "showIndentGuide": true,
  "useMarkdownLinks": true
}
```

### Essential Plugins

- **Core Plugins**: Graph view, Search, Quick switcher
- **Community Plugins**:
  - MathJax for equation rendering
  - Dataview for dynamic content
  - Tag Wrangler for tag management

## 🤝 Contributing

Contributions are welcome! Please follow these guidelines:

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/new-topic`

### Content Standards

- Mathematical notation should use LaTeX syntax
- All formulas must be properly formatted
- Include practical examples where applicable
- Cross-reference related topics using `[[Topic Name]]`
- Add appropriate tags: `#study #math #physics`
